# Что нужно от команды для запуска на H100

## До запуска

- [ ] **Доступ к серверу:** SSH-логин, 2×H100 свободны ~14 ч, ≥ 60 ГБ на диске.
- [ ] **Доступ к приватному GitHub-репозиторию** `w4std/-_-_-` с сервера (deploy key или токен). Иначе — скопировать папку репозитория архивом.
- [ ] **Интернет на сервере на ~15 минут** для `00_setup.sh` (пакеты и ImageNet-веса). Если его нет — см. раздел 4 README.
- [ ] **Архив данных** `dxaqc_h100_data.tar` собран на Mac (`bash h100_kit/make_data_archive.sh`) и передан на сервер своим каналом (scp/rsync/диск), **не через облака**. Готовая копия лежит в `~/Downloads/dxaqc_h100_kit/`.
- [ ] **Разрешение использовать внешние данные Arak** (зеркало Kaggle, CC BY-NC 4.0) для обучения. Нужно для DINO и ориентиров; для хакатона допустимо, для коммерческого внедрения — отдельный вопрос.
- [ ] *(необязательно)* **Ручная разметка v2** (`outputs/landmark_labeling/labeler_v2.html` → «Скачать JSON» → `landmarks_manual_v2.json` в ту же папку до сборки архива). Без неё ориентиры v2 учатся на автоматических точках малого вертела.

## Во время

- [ ] Запустить в `tmux` (README, п. 2.2), раз в несколько часов смотреть `outputs/h100_logs/gpu*.log`.
- [ ] При `FAILED` — лог соответствующего прогона в `outputs/h100_logs/`, таблица «Если что-то пошло не так».

## После

- [ ] `bash h100_kit/collect_results.sh` → прислать `h100_results_<дата>.tar.gz`.
- [ ] Если какая-то серия прошла критерий из README (п. 3) — дополнительно `collect_results.sh --weights`, чтобы забрать веса для релиза.
- [ ] На Mac: распаковать, пересчитать `scripts/evaluate_final.py`, решить по критериям, пересобрать бандл и Docker.
