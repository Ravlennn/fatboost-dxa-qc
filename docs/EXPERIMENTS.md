## CGMH ROI v1 — подготовка по запросу пользователя

- Статус: PREPARING (статус выполнения будет в outputs/cgmh_pipeline_v1/status.json).
- Источник: https://www.kaggle.com/datasets/tommyngx/cgmh-pelvisseg, версия 2. API перечисляет 400 Image + 400 Label основной коллекции и 140+140 дополнительных файлов. Используем только основную коллекцию; дополнительная исключена.
- Первая маска проверена визуально: бинарная сегментация проксимальных отделов двух бедренных костей, значения 0/255. Полный аудит архива выполняется до обучения.
- Лицензионное расхождение: API CC0, subtitle research/education only, PELE CC-BY-NC-SA. Локальный исследовательский эксперимент; внешние снимки не публикуем.
- Внешний сегментатор: небольшая U-Net с GroupNorm, 256px, 30 эпох, seed 42, BCE+Dice. 80/20 внешний image-level split после exact pixel dedup; patient IDs неизвестны. Полные и односторонние виды в train. Лучший checkpoint по внешнему validation Dice; не считаем его независимым тестом.
- Никакие DXA quality labels не используются для обучения/выбора сегментатора. ROI строится по крупнейшей компоненте p>=0.5, запас 15%; при пустой/неправдоподобной площади возвращается полный кадр. Параметры зафиксированы заранее.
- DXA-сравнение: cgmh_control_full_s0_v1 vs cgmh_full_plus_roi_s0_v1. Оба ConvNeXt, 384px, 30 эпох, seed 0 (+fold), все пять одинаковых локальных фолдов. Контроль обучается заново без переноса старых фолдов. Вторая модель усредняет логиты общего backbone для full и ROI; больше вычислений и аугментаций — ограничение интерпретации сравнения.
- Основная оценка: pooled OOF ROC-AUC и AP, парный бутстрап по исследованию, 1000 повторов, seed 42. Это не канонические фолды команды и не независимый тест. Производственную модель автоматически не меняем.
- Очередь ждёт завершения текущей пары ConvNeXt/DenseNet. Только один тренировочный процесс; 2 CPU threads, interop 1, nice 10, пауза 1 сек после каждого train/eval batch. Коммиты и хэши данных записываются в config/provenance.
- Артефакты: data/external/cgmh/prepared/audit.json и mask_audit.jpg; outputs/cgmh_roi_v1/{metrics.md,dxa_rois.json,dxa_roi_review.jpg}; outputs/cgmh_pipeline_v1/comparison.md. Новые метрики пока отсутствуют.
