## DICOM
- 499 файлов, все GE Lunar Prodigy Advance, Modality CR, 8 бит, MONOCHROME2, Implicit VR LE, один кадр.
- Размер ~280×260 (бедро) и ~300×315 (позвоночник). Ширина 300 = позвоночник, 280 (редко 248) = бедро.
- Заголовки пустые: нет BodyPartExamined, Laterality, PixelSpacing, ImagerPixelSpacing, PatientID = Anonymized. Область и сторону можно определить только по пикселям.
- Папка исследования (2.25.…) НЕ равна StudyInstanceUID внутри файла (1.2.643.…). Разметка ссылается на имя папки.
- Внутри исследования одни и те же снимки продублированы (до 29 файлов). После дедупликации по md5 пикселей: 252 уникальных изображения, по 1–3 на исследование. Между исследованиями дублей нет.

## Сторона бедра
Правое бедро: диафиз слева, таз справа (рентгеновская конвенция, подтверждено тестовыми файлами `_ППОБ/_ЛПОБ`). Эвристика: центроид кости в верхних 30% минус в нижних 30% по X; >0 → правое. На парах внутри исследования согласована в 100% случаев.

## Масштаб пикселя (добавлено после статьи UK Biobank про DXA ROI)
PixelSpacing в DXA GE Lunar не пишется, но есть тег `ExposedArea (0040,0303)` = [ширина, высота] в мм. Проверка на 252 изображениях:
- Позвоночник при ExposedArea[0]=180: `ea1/rows = 0.606 мм/px` со std 0.001, корреляция с Rows = 1.0. Ширина 180/300 = 0.60 мм/px.
- Бедро при ExposedArea=[170, …]: 170/280 = 0.607; высоты 143/159/160 мм ↔ 235/261/265 строк, тоже 0.607. Узкие бёдра 248 px ↔ 150 мм.
- Но тег относится к исследованию, а не к снимку: в 49 из 100 исследований он одинаковый у всех снимков, встречаются 0 и значения 520×615 (всё тело), TotalNumberOfExposures до 6.

Вывод: рендер DICOM у Lunar Prodigy идёт с шагом **≈0,6 мм/px по обеим осям**, ширина кадра фиксирована протоколом (300 px позвоночник = 18 см, 280 px бедро = 17 см). Правило: если ExposedArea согласуется с матрицей (оба отношения в 0,55–0,65), брать его, иначе константа 0,6 мм/px. Для критерия ROI бедра: 3 см ≈ 50 px, 2 см ≈ 33 px.

Также `PatientOrientation = [L, F]` у всех снимков: ось X к левой стороне пациента, то есть правая сторона пациента слева на экране. Подтверждает конвенцию для стороны бедра.
