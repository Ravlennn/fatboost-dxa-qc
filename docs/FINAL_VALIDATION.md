## Протокол

- **Данные:** 249 размеченных кадров (99 позвоночник, 150 бедро) из 100 исследований; 5 внешних фолдов по исследованиям — те же, что у релиза.
- **Никакое решение не видит свой фолд:**
  - CNN-скоры — OOF релиза;
  - головы по ориентирам, малому вертелу и детектору артефактов переобучаются на outer-train;
  - **каждый порог** выбирается по F1 на outer-train: внутренние 3 фолда для голов, OOF других фолдов для CNN.
- **Правило решения как в CLI:**
  - **позвоночник:** брак = найдена хотя бы одна причина (ось по ориентирам, поля/гребни по ориентирам, артефакт = CNN + детектор). Это правило выбрано **внутри каждого внешнего фолда** из двух заранее заданных вариантов («CNN ИЛИ причины» / «только причины») по F1 на обучающей части. Выбрано 5 раз из 5;
  - **бедро:** брак = fusion (CNN + малый вертел); `hip_positioning` = fusion; `hip_roi_margins` = CNN;
  - причины выдаются только при браке; брак без причины = `quality_unspecified`.
- **ROC-AUC / PR-AUC составного решения** — по скору max(скор/порог) по компонентам: он ≥ 1 ровно тогда, когда решение «брак».
- **95% ДИ:** 2000 bootstrap-повторов по исследованиям.
- **«До»** — прежняя сборка только на CNN, тем же протоколом.

**3. Мало параметров, подобранных по меткам.** Каждая новая голова — логистическая регрессия на 2–5 признаках. Сами признаки берутся из моделей и детекторов, которые метки качества не видели: ориентиры обучены на Arak, детекторы вертела и артефактов разработаны на снимках со скрытыми метками.

**4. Оптимизм поставляемых порогов.** Пороги в бандле подобраны на всех OOF сразу. На этих же данных они дают F1 качества 0.700 против честных вложенных 0.667: примерно +0.03 оптимизма. Поэтому в презентации — только вложенные цифры.

**Что эти проверки НЕ исключают.** Мы много раз работали с одними и теми же 249 снимками: выбирали, какие гипотезы пробовать, настраивали детекторы по картинкам (без меток). Такой исследовательский оптимизм перестановочный тест не ловит. Реальная ожидаемая оценка на закрытом тесте — нижняя половина доверительных интервалов, особенно для редких причин. Кроме того, все снимки — один аппарат (GE Lunar Prodigy) и один центр.

## Как читать и что говорить

- **Главные приросты — объяснимые причины и качество позвоночника:**
  - артефакты: F1 0.52 → 0.77;
  - наклон оси: F1 0.17 → 0.48;
  - границы сканирования: F1 0.10 → 0.43;

  - качество по всем областям: F1 0.59 → 0.67, AUC 0.76 → 0.83.
- **Ротация бедра:** AUC вырос (0.78 → 0.83), F1 при вложенном пороге нет (0.59 → 0.58). Порог нестабилен на 150 бёдрах; это главная задача для ансамбля на H100.
- **Чувствительность качества** снизилась (0.82 → 0.67) ради специфичности (0.59 → 0.86). Это компромисс, выбранный по F1 (приоритет ТЗ). Если организаторам важнее не пропустить ни одного брака, для позвоночника есть вариант «CNN ИЛИ причины» (чувствительность 1.0, специфичность 0.30).
