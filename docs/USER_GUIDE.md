# Руководство пользователя

Для врача-рентгенолога, рентгенлаборанта и специалиста по контролю качества. Программа проверяет снимки денситометрии (DXA) поясничного отдела позвоночника и проксимального отдела бедра по критериям качества из методических рекомендаций. Она не ставит диагноз и не оценивает минеральную плотность кости: только укладку, границы сканирования, область интереса и посторонние предметы.

Решение программы — подсказка. Окончательное решение принимает специалист.

## Запуск

Администратор запускает сервис одной командой (подробно — [развёртывание](DEPLOYMENT.md)):

```sh
./scripts/run-ui.sh            # в контейнере; порт открыт только на 127.0.0.1
```

Затем откройте в браузере адрес, который напечатала команда (по умолчанию `http://127.0.0.1:8080/`). Интернет не нужен: снимки не покидают компьютер, всё считается локально.

## 1. Загрузка

Перетащите в окно ZIP-архив, папку или отдельные файлы DICOM либо нажмите «Выбрать файлы» / «Выбрать папку». Подходят:

- снимки поясничного отдела позвоночника (L1–L4) и проксимального отдела бедра, правого и левого;
- архивы внутри архивов и папок, имена на кириллице, архивы из Windows.

Документы, таблицы и картинки, лежащие рядом со снимками, пропускаются. Повреждённый или пустой файл не останавливает пакет: он появится в списке со статусом «Ошибка» и причиной.

## 2. Обработка

Строки появляются по мере анализа, полоса вверху показывает прогресс. На обычном компьютере один снимок занимает несколько секунд. Можно открывать готовые снимки, не дожидаясь конца пакета. Адрес страницы (`#job=…`) можно обновить или добавить в закладки — пакет не потеряется, пока сервис запущен.

Счётчики вверху: **Норма**, **Брак**, **Ошибки** (файлы, которые не удалось прочитать) и **Проверено** (снимки, подтверждённые специалистом).

## 3. Список снимков

Фильтры над списком: «Все / Брак / Норма / Ошибки» и область («Бедро Л», «Бедро П», «L1–L4»). Клавиши `↑` и `↓` переходят к соседнему снимку. Для каждого файла видны область, вердикт и найденные нарушения. Значок щита — снимок уже проверен специалистом.

## 4. Просмотр снимка

Справа — снимок с разметкой, под ним — карточки критериев. Снимок и причины видны одновременно, без прокрутки.

**Позвоночник.** Уровни L1–L4, ось позвоночника с углом наклона в градусах, поля над L1 и под L4 в миллиметрах. Критерии:

| Критерий | Норма по методичке | Текст в отчёте при нарушении |
|---|---|---|
| Границы сканирования | снизу видны верхние края подвздошных костей, сверху — половина Th12 | Некорректная укладка |
| Ось позвоночника | наклон не больше 5° | Не выровнена ось позвоночника |
| Посторонние предметы | нет металла, косточек белья и наложений | Присутствуют посторонние предметы |

**Бедро.** Рамка области интереса (ROI) с полями в миллиметрах, ось шейки бедра, контур малого вертела. Критерии:

| Критерий | Норма по методичке | Текст в отчёте при нарушении |
|---|---|---|
| Ротация бедра | малый вертел слегка выступает за контур кости | Некорректная укладка |
| Поля области интереса | 3 см сверху и снизу, 2 см сбоку | Некорректная область интереса |

Нарушенный критерий выделен красным, на снимке подсвечено, где именно найдено нарушение. Инструменты на снимке:

- **Разметка** (клавиша `M`) — скрыть или показать разметку;
- **Сравнить** — шторка: слева снимок с разметкой, справа чистый; шторку можно двигать мышью;
- **Исправить** — коррекция разметки (см. ниже);
- **Подтвердить** — согласиться с решением программы.

Если программа сомневается (например, общий классификатор видит брак, а ни одна причина не превысила порог), под снимком появится пометка «причина выведена»: указана причина, ближе всего подошедшая к порогу. Такие снимки стоит посмотреть особенно внимательно.

## 5. Проверка и коррекция специалистом

1. **Согласны с программой** — нажмите «Подтвердить». Снимок получит отметку «проверено».
2. **Разметка неточна** — нажмите «Исправить». На снимке появятся точки: границы позвонков L1–L4 или края рамки ROI и ось шейки. Перетащите их мышью или пальцем. Можно выбрать точку и двигать её стрелками (с `Shift` — по 5 пикселей). Миллиметры и градусы пересчитываются сразу. Когда точку отпускают, программа заново оценивает все критерии по новой разметке и заново ищет малый вертел. «Сбросить» возвращает точки программы, «Отмена» выходит без изменений, «Подтвердить» сохраняет.
3. **Не согласны с решением по критерию** — на карточке критерия выберите «Нарушение» или «Норма». Это решение имеет приоритет над программой.

Подтверждённое решение заменяет решение программы в отчёте CSV/XLSX и в DICOM SR. Программа не удаляет свою исходную оценку: она сохраняется в выгрузке исправлений и в SR отдельной строкой.

## 6. Выгрузка результатов

Кнопки вверху становятся доступны после обработки пакета:

- **CSV / XLSX** — таблица по форме ТЗ: путь, UID исследования и снимка, область, класс качества (0 — качественное, 1 — есть нарушение), нарушения через «;», статус обработки, время в секундах и вероятность нарушения `quality_prob`;
- **SR** — ZIP-архив DICOM SR: на каждый снимок текстовый структурированный отчёт в том же исследовании, отдельной серией «DXA QC report (AI)». Его можно отправить в PACS рядом со снимками. Непроверенные отчёты помечены `UNVERIFIED`, подтверждённые специалистом — `VERIFIED`;
- **Исправления** (появляется после первой проверки) — JSON с точками и решениями программы и специалиста. Это готовая экспертная разметка для дообучения модели ([обучение](TRAINING.md)).

«Новый пакет» открывает загрузку заново; предыдущий пакет остаётся доступен по его адресу, пока сервис запущен. Загруженные снимки хранятся во временной папке и удаляются при остановке сервиса.

## Командная строка

Для пакетной обработки без интерфейса:

```sh
dxaqc -i исследования.zip -o результат.xlsx --sr sr.zip --overlays разметка.zip
```

`--sr` сохраняет DICOM SR, `--overlays` — картинки с разметкой (PNG и отдельная DICOM-серия Secondary Capture). Описание всех параметров — в [README](../README.md).

## Частые вопросы

**Статус «Ошибка» у файла.** Файл не является снимком DICOM, повреждён, пуст или содержит однотонный кадр. Причина указана в строке. Остальные файлы пакета обработаны.

**Снимок не той области.** Программа отсекает снимки вне задачи (например, предплечье или всё тело): они получают статус «Ошибка» с пояснением, без вердикта.

**Миллиметры отличаются от консоли денситометра.** Масштаб берётся из DICOM; если его нет — 0,6 мм на пиксель (типичный для GE Lunar). На решения программы масштаб не влияет, только на показанные миллиметры.

**Можно ли доверять «Норме»?** На выборке разработки программа находит около трёх четвертей нарушений при специфичности около 0,8 (метрики с доверительными интервалами — в README). Спорные снимки проверяйте глазами.
