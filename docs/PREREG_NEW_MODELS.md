# Предрегистрация: четыре новые модели (A–D)

Зафиксировано 2026-10-16 до первого запуска. Код, рецепты и критерии ниже не меняются после
появления результатов. Ожидание до запуска — у каждой ветки прирост маловероятен, но ни одна из
идей раньше не проверялась в таком виде.

## Контроль

Опубликованная полностью изолированная сборка: позвоночник — `decisions_isolated.csv`,
бедро — `decisions_hip_nested.csv` (25 вложенных CNN). AUC качества: все 0.828, позвоночник 0.810,
бедро 0.841. Оба оценщика без новых моделей воспроизводят контроль побитово
(`eval_spine_nested.py --check-control`, `eval_hip_nested.py`).

## Ветки

Общий рецепт (`scripts/qc_cnn_common.py`) повторяет `train_hip_cnn.py`: AdamW, OneCycle, 30 эпох,
seed + fold, взвешенный BCE по известным меткам, те же 5 фолдов. Изоляция — 25 обучений на ветку
(`scripts/run_nested.sh`): 5 базовых (без внешнего фолда f) + 20 вложенных (без f и j); вторая
ступень на внешних обучающих строках видит только оценки вложенных моделей.

| Ветка | Модель | Куда встраивается | Главная метрика |
|---|---|---|---|
| A | ConvNeXt-Tiny 384, позвоночник, 4 выхода (качество, границы, ось, предметы); только яркость/контраст | логит соответствующего выхода — доп. признак в каждой голове причины позвоночника; политика «брак = любая причина» не меняется | ΔAUC качества позвоночника |
| B | ConvNeXt-Tiny 384, общая для обеих областей, 7 выходов, потери по маске своей области; аугментации своей области | позвоночник — как A; бедро — вместо нынешней CNN бедра | ΔAUC качества по всем областям |
| C | ConvNeXt-Tiny 224 на вырезе 60 мм вокруг вершины малого вертела (детектор по точкам сети ориентиров), выходы: качество, ротация; только яркость/контраст | логит — доп. признак в головах качества и ротации бедра | ΔAUC качества бедра |
| D | RAD-DINO ViT-B/14 (microsoft/rad-dino @110cbc18, SHA-256 1eac0464…), LoRA r=8 на qkv и proj всех блоков + линейная голова на [CLS, средний патч]; 336 px; lr 2e-4 (голова ×10), batch 8; аугментации как у CNN бедра | логит — доп. признак во всех трёх головах бедра | ΔAUC качества бедра |

## Критерий

- Сравнение — `scripts/compare_arms.py`: те же 249 снимков, бутстрэп по исследованиям, 4000 повторов.
- Поправка Бонферрони на все четыре ветки: интервал 98.75%.
- Ветка принимается, только если интервал главной метрики целиком выше нуля. Остальные метрики
  (F1 качества, F1 и AUC причин) — только в отчёт.
- Если проходят несколько веток, в релиз идёт одна — с наибольшей нижней границей; их сочетание —
  отдельная гипотеза с новой предрегистрацией.

## Результат (2026-10-16)

Все 100 обучений завершены без сбоев. Интервал 98.75%, бутстрэп по исследованиям, 4000 повторов
(`outputs/final_validation_isolated/prereg_new_models_result.txt`).

| Ветка | Главная метрика | Контроль → ветка | Δ [98.75% ДИ] | Решение |
|---|---|---|---|---|
| A | AUC качества позвоночника | 0.810 → 0.792 | −0.017 [−0.097; +0.042] | отклонить |
| B | AUC качества, все области | 0.828 → 0.784 | −0.045 [−0.089; +0.000] | отклонить |
| C | AUC качества бедра | 0.841 → 0.887 | +0.046 [−0.014; +0.120] | отклонить (граница) |
| D | AUC качества бедра | 0.841 → 0.832 | −0.009 [−0.069; +0.043] | отклонить |

По заранее заданному критерию ни одна ветка не принята; релиз не меняется.

C — единственная ветка, где выросли все метрики бедра сразу: F1 качества бедра 0.653 → 0.702,
ротация F1 0.595 → 0.693 и AUC 0.827 → 0.870, AUC качества по всем областям 0.828 → 0.861.
Без поправки на четыре ветки 95% интервал главной метрики [−0.002; +0.102], прирост в 96.9%
бутстрэп-повторов. Это не доказательство; включение C в релиз — отдельное решение, которое
требует отдельной подтверждающей проверки или явной пометки о недоказанности.

Дообучение на позвоночнике (A, B) ухудшает границы сканирования (AUC 0.876 → 0.77 / 0.72):
99 снимков мало, а общая сеть (B) ещё и ухудшает бедро. Большая модель на всём кадре (D) не
добавляет ничего к нынешней сборке бедра; помогает только прицельный взгляд на малый вертел (C).

**Подтверждающая проверка C (2026-10-18, [PREREG_C_CONFIRM.md](PREREG_C_CONFIRM.md)):** тот же рецепт с seed 1 — ΔAUC качества бедра +0.029 [−0.021; +0.087], C не подтверждена, релиз не меняется.
