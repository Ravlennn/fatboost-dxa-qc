# Design — «Негатоскоп»

Графитовое окружение кабинета чтения снимков: серые DXA-снимки читаются без искажений, цвет расходуется только на смысл.

## Tokens (`ui/src/styles.css`)

| Роль | Значение |
|---|---|
| Окружение / панель / приподнятый слой | `#141619` / `#1a1d21` / `#21252a` |
| Подложка снимка | `#0b0c0e` |
| Текст: основной / вторичный / третичный | `#ecebe7` / `#aeaba4` / `#7c7973` |
| Восковой карандаш (разметка, основное действие, фокус) | `#f2c14e` |
| Норма / брак / ошибка | `#8cc097` / `#ef7358` / `#9aa4b2` |
| Радиусы | панели 14px, элементы 9px, чипы — капсула |

## Type

Golos Text — интерфейс и текст (кириллица, язык российских госсервисов). Fira Sans Condensed — подписи, счётчики и измерения, табличные цифры. Оба шрифта упакованы в сборку.

## Components

Кнопки (обычная, основная жёлтая, тихая), сегментированные фильтры со счётчиками, строки списка с миниатюрой и чипом вердикта, просмотрщик со слоем разметки, шторка сравнения, карточки критериев ТЗ.

## Annotation grammar

Размерные линии технического чертежа с поперечными засечками, пунктирная опорная ось, подписи на жёлтой плашке; нарушенный критерий — красным. Линии — SVG в координатах снимка с постоянной толщиной, подписи — HTML постоянного размера.

## Motion

- Кривые: `cubic-bezier(0.23, 1, 0.32, 1)` для появления, `cubic-bezier(0.77, 0, 0.175, 1)` для шторки.
- Главный момент — «проявление» готового снимка (760 мс, один раз и только при живом поступлении) и прорисовка разметки «карандашом» при первом открытии снимка (520 мс, пропускается при быстром листании).
- Клавиатурные действия не анимируются; нажатие кнопок — `scale(0.97)`.
- `prefers-reduced-motion`: движение убирается, остаются смены прозрачности.
